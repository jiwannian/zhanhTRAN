# Security

Do not post API keys, document contents, Zotero profiles, or personal logs in issues.
Report vulnerabilities privately using GitHub's private vulnerability reporting when available.
For ordinary bugs, include the plugin/Zotero versions and a minimal synthetic reproduction.

Provider requests contain extracted document text. Configure only trusted HTTPS providers;
plain HTTP is allowed only for loopback testing. Source instructions are treated as document data.
Keep Python and its PDF/image/OCR dependencies updated and process only trusted documents.
